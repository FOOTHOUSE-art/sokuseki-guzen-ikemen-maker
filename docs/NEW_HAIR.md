# 髪型を足す — GPT で原画を作るとき

素材は全点が同じ座標に描かれている。**そこを外すと合成でずれる。**
だから「文章で座標を指定する」のではなく、**素体を見せて髪だけ足させる。**

```bash
python3 tools/hair_guide.py base
```

`build/hair_base.png`(線なし)と `build/hair_base_guide.png`(線あり)が出る。
**GPT に渡すのは線の無いほう。** 線ごと描き写してくる。

---

## 1. GPT に渡すもの

- `build/hair_base.png`(髪も眉も眼鏡も無い素体。1024×1024)
- 既存の髪素材を1〜2点(絵柄を合わせるため)。
  `assets/11_hair/hair20_shortpart.webp` あたりが素直
- 下のプロンプト

## 2. プロンプト（そのまま貼る）

```
添付した1枚目は、この人物の素体です。**頭・顔・耳・首・肩の形と位置は1ピクセルも動かさないでください。**

この頭に、次の髪型だけを足した画像を1枚作ってください。

【髪型】
（ここに書く。例：やや長めのセンターパート。毛先は肩に届かず、
耳が半分隠れる。前髪は眉の下すれすれ。毛流れは外側にゆるく流れる）

【守ること】
- 出力は 1024×1024 の正方形。背景は真っ白（#FFFFFF）で、影も模様も入れない
- 顔・耳・首・肩は添付のまま。**輪郭線を描き足さない**
- 髪の色は暗めの茶色（#3B2C22 前後）の単色寄りで描く。あとから色を変えるので、
  金髪や派手な色にしない
- 光は正面からの均一光。強いハイライトや逆光は入れない
- 2枚目の素材と**同じ絵柄・同じ塗り**にする。写真風にしない
- 髪のいちばん上は、画像の上端から 60〜200px の範囲に収める
- 眉・眼鏡・服・帽子は描かない
- 目安線や枠線、文字、透かしは入れない
```

**髪型の書き方は、素材の名前を参考にする。**
`hair11_mushroom`(マッシュ)、`hair17_sweptpart`(かき上げのサイドパート)、
`hair25_twistperm`(ツイストパーマ)、`hair29_wavymedium`(波巻きのミディアム)。

## 2'. 髪型の参照画像を使うとき

**参照画像から取るのは「髪の形」だけ。** 顔も画風も光も色も取らない。
ここを分けて書かないと、参照の人物の顔に引っ張られる。
基準カードの前置きと同じ考え方(`docs/PLAN.md` §4-2)。

渡すもの: 1枚目=素体、2枚目=髪型の参照、3枚目=既存の髪素材(絵柄合わせ・任意)

```
1枚目はこの人物の素体、2枚目は髪型の参照です。

2枚目から読み取るのは**髪の形だけ**にしてください。
　・長さ、前髪の落ち方、分け目の位置、毛量、毛流れ、耳の隠れ方、襟足の形

2枚目から読み取らないもの:
　・顔立ち、輪郭、肌の色、年齢、表情 … すべて1枚目のまま
　・写真らしさ、光の向き、影、背景 … すべて下の指定に従う
　・髪の色 … 暗めの茶色（#3B2C22 前後）に置き換える
**2枚目の人物に似せないでください。** 髪の形だけを写します。

1枚目の頭に、その髪型を足した画像を1枚作ってください。

【守ること】
- 出力は 1024×1024 の正方形。背景は真っ白（#FFFFFF）で、影も模様も入れない
- 顔・耳・首・肩は1枚目のまま。輪郭線を描き足さない
- 参照が横向き・斜めでも、**正面から見た形に直して**描く
- 参照が写真でも、**1枚目と同じ絵柄・同じ塗り**にする。写真風にしない
- 光は正面からの均一光。強いハイライトや逆光は入れない
- 髪のいちばん上は、画像の上端から 60〜200px の範囲に収める
- 眉・眼鏡・服・帽子は描かない。目安線・文字・透かしも入れない
```

### 参照が実写だと起きること

| 起きること | 効く一文 |
|---|---|
| 顔が参照の人に寄る | 「2枚目の人物に似せないでください」 |
| 写真調になる | 「1枚目と同じ絵柄・同じ塗り」 |
| 髪だけ妙に精細になる | 同上。既存素材を3枚目に付けると効きが上がる |
| 逆光や強い影が付く | 「正面からの均一光」 |
| 髪色が参照のまま | 「#3B2C22 前後に置き換える」 |

### 髪型を言葉でも書き足す

参照があっても、**言葉を添えたほうが安定する。** 6つ書けば足りる。

| | 例 |
|---|---|
| 長さ | 襟足が首の中ほど / 耳の下 / 肩に触れる |
| 前髪 | 眉の下すれすれ / 眉が見える / 上げて額を出す |
| 分け目 | 中央 / 左に7:3 / 分けない |
| 毛量 | 多め / 標準 / 透けるくらい薄め |
| 毛流れ | 外にはねる / 内に入る / 後ろに流す |
| 耳 | 全部見える / 半分隠れる / 完全に隠れる |

## 3. 返ってきたら測る

```bash
python3 tools/hair_guide.py check <返ってきた画像>
```

| 見るもの | 落ちたら |
|---|---|
| 1024×1024 か | 別の大きさで出ている。作り直させる |
| 背景が白く均一か | 影や模様が入っている。抽出が汚れる |
| 頭のてっぺんが 60〜200px か | 頭の位置がずれている。**合成で頭が浮く** |
| 下端が 700px より下か | 肩まで入っているか |
| 赤い目安線が残っていないか | 線ありのほうを渡している |

**ここを通らないものを先に進めない。** あとの工程で必ず困る。

## 4. 髪を切り出す

**素体から作った絵なら、差分で切れる。**

```bash
python3 tools/import_hair.py --batch <一覧ファイル>
python3 tools/import_hair.py --install
```

一覧ファイル(例 hairs.json)はこの形。

```json
[{"path":"新しい髪.png","id":"hair31_flowbang","ja":"流し前髪のショート",
  "map":["短髪","斜めに流した前髪（左流し）","ワックスの束感セット"]}]
```

`map` の3つは偶然メーカーの語彙から選ぶ(髪型 / 前髪 / 整髪)。

### なぜ差分で切れるか

素体を渡して描かせているので、返ってくる絵は**顔・耳・首・肩が素体とほぼ同じ**。
実測すると顎の先が ±5px、耳の高さの顔幅が ±3px。
だから「素体と違うところ = 髪」で足りる。

局所分散を使う `pipeline_v18.py` は、**素体が無い原画のためのもの**。
素体から作った絵なら差分のほうが確実で、幽霊の髪も出ない。

### 顎の輪郭線を髪と間違える

GPT は輪郭線を引き直すので、そこも素体との差になる。しかも暗い。
**髪は太く、輪郭線は細い。** 細いもの(3px未満)を落とすと分かれる。
これを入れる前は、生え際が 770(顎の下)と出ていた。

抜けや残骸が残ったら `tools/mask_editor.html` で手直しする。

抜けや残骸が残ったら `tools/mask_editor.html` で手直しする。
**原画を一緒に読み込むと、抜けを原画から戻せる。**

## 5. 置く場所と、直す5か所

`--install` が全部やる。手でやるなら下のとおり。

| | |
|---|---|
| 1 | `assets/11_hair/hair31_〇〇.webp` に置く（**番号は続きから**） |
| 2 | `assets/crop.json` に `"11_hair/hair31_〇〇.webp": [x, y, w, h]` |
| 3 | `assets/metrics.json` の `hair` に `"hair31": {"hairline": 生え際のy}` |
| 4 | `assets/parts.json` の `axes.hair.options` に `{"id":"hair31_〇〇","w":1}` |
| 5 | `engine/face_text.js` の **`JA.hair`** と **`M.hair`** に語彙 |

**5を忘れると、その髪型が出たときプロンプトに `undefined` が混ざる。**
画面を見ても気づきにくい。

`crop` と `hairline` は `tools/import_hair.py` が出す。

**`engine/` の `crop.json` `metrics.json` `parts.json` は検査用のコピー。**
`assets/` と同じにしておく。ここを忘れると node 側だけ古い素材で動き、
**「指定した髪型にならない」**という分かりにくい形で出る(実際に踏んだ)。
`npm test` が両者を突き合わせている。

### `engine/face_text.js` の書き方

```js
// JA.hair — 画面とプロンプトに出す日本語
hair31_wolfshort: 'ショートウルフ',

// M.hair — 人物像側の語彙に橋渡しする。[髪型, 前髪, 整髪]
hair31_wolfshort: ['ウルフミディアム', '眉にかかる重め前髪', '無造作セット'],
```

`M.hair` の3つは偶然メーカーの語彙から選ぶ。無いものを書くと、
人物像側の服装や雰囲気の重みづけが既定に落ちる（落ちても止まりはしない）。

## 6. 足したら流す

```bash
node engine/test_vocab.mjs   # 語彙・実測・crop・undefined を突き合わせる
npm test                     # 全部
```

`test_vocab` が **5 を忘れていないか**を見ている。

## 7. うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 合成すると頭が浮く／めり込む | `crop.json` の y。`hair_guide.py check` の「いちばん上」 |
| 耳の上に暗い欠けが出る | 描画順。**耳→髪の順は変えない** |
| 毛先が途中で切れる | 切り抜きの範囲。1024の全面で作業してから切り詰める |
| 色を変えると不自然 | 原画が単色寄りでない。金髪などで作らせると起きる |
| もみあげが薄い | `mask_editor.html` の「戻す筆」で原画から戻す |
