# ローカルで動かす

即席メーカー v0.9157 に、統合エンジンの差分3本を当てたもの。**v0.9300**。

```
python3 serve.py
```

→ http://localhost:8000/

Windows は `start.bat` をダブルクリック。

**`serve.py` を使うこと。** 通常の `http.server` だとブラウザが古い JS を掴んだままになる。
画面上部のタイトルに版が出る。`v0.9300` でなければ **Ctrl + Shift + R**。

---

## 何が変わったか

### 1. 服に「なし」が増えた

「装い → 服」に **なし** が出る。素肌の肩まで写る。
**顔の参照画像としてはこれがいちばん安全**で、襟が本文の服装に混ざらない。

### 2. URLに微調整と固定が乗る

これまで `#3361465794` はシードだけだった。**微調整25項目と固定した軸が復元されなかった。**

```
#3361465794!cloth:none!browY:19,eyeGap:-24,eyeHeight:75!0.9157
```

「URLをコピー」で取ったものを別のタブで開くと、**つまみの位置まで同じに戻る。**
スタンプと筆は入らない。打っているときは画面下に「URLに含まれません」と出る。

### 3. 左に3つのカードが増えた

| | |
|---|---|
| **人物像** | 名前・年齢・職業・身長体重・体型・MBTI。**同じシードから決まる** |
| | その下にレア判定(顔+人物像)の内訳 |
| **生成AI向け** | 顔の記述(素材IDから作った日本語)/ 基準カードのプロンプト / 派生20種 |

---

## 最初に確かめること

1. **ガチャを回す。**画面が出て、左に人物像とプロンプトが出る
2. **イケメン度の数字と、レア判定の欄が食い違っていないか**
   統合エンジンは同じ値を別経路で計算している。**ずれていたら渡し忘れ**
3. **微調整を動かす。**「目の間隔がはっきり狭い」などの語が増減する
4. **服を「なし」にする。**素肌の肩まで出る
5. **URLをコピーして別のタブで開く。**顔・微調整・プロンプトが同じ
6. **「基準カードを写す」を押して、生成AIに貼る。**画像も一緒に添付する

## 使いかた — 参照画像を作る

```
[1] ここで顔を作る          → 「画像を保存」で 1024×1024 PNG
[2] 「基準カードを写す」     → 生成AIに貼り、[1] の画像を添付する
        ↓ 返ってきた16:9のカードを保存
[3] 派生を選んで「派生を写す」 → 生成AIに貼り、[2] の画像を添付する
```

**[2] に添付するのは顔の画像、[3] に添付するのは基準カードの画像。**
間違えると構図が混ざる。

## うまく動かないとき

| 症状 | 見るところ |
|---|---|
| 版が `v0.9157` のまま | Ctrl + Shift + R。`serve.py` を使っているか |
| 「生成AI向け」に赤い文字 | そこにエラーが出る。ブラウザのコンソールも見る |
| 人物像が空 | `face_presets.json` が置かれているか |
| イケメン度と食い違う | `renderPrompt` に渡している `ov` / `adjUsed` |
| 顔は変わるのに文章が変わらない | 同上 |

ブラウザのコンソール(F12)に赤が出ていないかを最初に見る。

## 差分を当て直す

素の v0.9157 から作り直すとき。

```
python3 apply_patches.py <アプリのフォルダ> <統合エンジンのフォルダ>
```

**同じ置換を2回当てても壊れない**(当たっていれば飛ばす)。
置換が見つからなければ止まる。文字列の置換は空振りしても通ってしまうため。

差分の中身は統合リポジトリの `docs/PATCH_*.md` にある。
